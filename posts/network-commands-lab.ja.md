# 実験1 よく使うネットワークコマンド


## 1、実験目的

- Linuxコマンド端末とWindowsコマンドラインの使い方を理解する
- よく使うネットワークコマンドの基本的な使い方に習熟する
- `ping`、`ifconfig`、`traceroute`、`arp`、`netstat`に基づくネットワーク状態の分析・測定技術を習得する

## 2、実験環境

- ハードウェア要件：Alibaba Cloud ECSクラウドサーバー 1台。
- ソフトウェア要件：Linux/ Windows オペレーティングシステム

## 3、実験内容


### 3.1 pingの基本的な使い方


pingコマンドを使用して、ネットワークの接続性をテストする。これは、ネットワークが正しく接続されているか、またネットワーク接続がどのような状態にあるかを確認するうえで非常に役立つ。pingが正常に動作すれば、ネットワークアクセス層、ネットワークカード、モデムの入出力回線、ケーブル、ルーターなどの障害をおおむね除外でき、問題の範囲を絞り込める。


```plain text
ping -c 4  www.baidu.com
ping -c 4  166.111.4.100
```


### 3.2 ifconfig/ipconfig（Windows）の基本的な使い方


ifconfigユーティリティを使用すると、現在のTCP/IP構成の設定値を表示できる。これらの情報は通常、手動で構成したTCP/IP設定が正しいかどうかを確認するために使用される。


```plain text
ifconfig
ifconfig eth0
```


### 3.3 tracerouteの基本的な使い方


tracerouteコマンドを使用してルーティング状況を測定する。つまり、パケットが宛先ホストに到達するまでに通過する経路を表示する。


```plain text
traceroute www.sohu.com
traceroute 166.111.4.100
```


### 3.4 arpの基本的な使い方


ARPはTCP/IPプロトコル群における重要なプロトコルであり、IPアドレスに対応するネットワークカードの物理アドレスを特定するために使用される。`arp`コマンドを使用すると、ローカルコンピューターまたは別のコンピューターのARPキャッシュに現在保存されている内容を確認できる。


```plain text
arp –a
arp -i eth0
```


### 3.5 netstatの基本的な使い方


netstatコマンドは、アクティブなTCP接続、コンピューターが待ち受けているポート、イーサネットの統計情報を表示できる。netstatはアクティブなTCP接続を表示する。


```plain text
netstat –a
netstat -t
```


## 4、実験結果と分析


### 4.1 pingの基本的な使い方


```plain text
ping -c 4  www.baidu.com
ping -c 4  166.111.4.100
```


![p4lJiLgDakWBonr.png](https://s2.loli.net/2022/06/09/p4lJiLgDakWBonr.png)


image-20220409224423767


PingはTCP/IPネットワークアーキテクチャのアプリケーション層で動作するサービスコマンドであり、主に特定の宛先ホストへICMP（Internet Control Message Protocol、インターネット制御メッセージプロトコル）Echo要求メッセージを送信し、宛先が到達可能かどうかをテストして、その状態を確認する。ネットワーク到達性テストでは、pingコマンドがICMPエコー要求メッセージと応答メッセージを生成する。宛先ホストはICMPエコー要求メッセージを受信すると、直ちに応答メッセージを返す。送信元ホストがICMPエコー応答メッセージを受信できれば、そのホストまでのネットワークが正常であることを示す。


Linuxでは、パラメーターcを使用して、送信（または受信）するエコー要求の数を指定できる。ここでは、`www.baidu.com`と`166.111.4.100`に接続できるかをテストした。スクリーンショットでは4個のパケットがすべて正常に受信され、損失がないことから、ネットワークが接続され、ホスト`www.baidu.com`と`166.111.4.100`に到達可能であることが分かる。平均往復遅延は、それぞれ10.105msと31.997msである。


### 4.2 ifconfig/ipconfig（Windows）の基本的な使い方


```plain text
ifconfig
ifconfig eth0
```


![3vtchm2ryeR1kXa.png](https://s2.loli.net/2022/06/09/3vtchm2ryeR1kXa.png)


image-20220409230049094


`ipconfig`は、Windowsシステムでネットワーク構成情報を確認するためのコマンドである。Windowsの`ipconfig`ユーティリティを使用すると、現在のTCP/IP構成の設定値を表示できる。これらの情報は通常、手動で構成したTCP/IP設定が正しいかどうかを確認するために使用される。


`ifconfig`は、Linuxシステムでネットワーク構成情報を表示または設定するためのコマンドである。ifconfigを使用すると、カーネル内のネットワークインターフェースを確認、構成、有効化、または無効化できる。このツールは非常によく使用され、システム起動時には必要なネットワークインターフェースのパラメーターを設定するために用いられる。このツールを使用して、ネットワークカードのIPアドレス、サブネットマスク、ブロードキャストアドレス、ゲートウェイなどを一時的に構成できる。また、設定をファイル（例：`/etc/rc.d/rc.local`）に書き込むこともできる。これにより、システム起動後にそのファイルが読み込まれ、ネットワークカードにIPアドレスが設定される。


`ifconfig`はネットワークデバイスの情報を表示でき、`ifconfig eth0`は1枚目のネットワークカードであるeth0の情報のみを表示できる。ここではホストのネットワークデバイス情報を確認した。このホストの最大伝送単位が`1500`であることに加え、ネットワークカードのIPアドレス（`172.16.2.6`）、ブロードキャストアドレス（`172.16.2.255`）、サブネットマスク（`255.255.255.0`）を確認できる。


一方、loはホストのループバックアドレスを表す。これは通常、ネットワークプログラムをテストする際に、LANや外部ネットワークのユーザーには公開せず、このホスト上でのみ実行・確認できるようにするために使用されるネットワークインターフェースである。たとえば、HTTPDサーバーをループバックアドレスに指定すると、ブラウザーに`127.0.0.1`と入力することで構築したWEBサイトを表示できる。ただし、閲覧できるのは自分だけであり、LAN内のほかのホストやユーザーが知ることはできない。


### 4.3 tracerouteの基本的な使い方


```plain text
traceroute www.sohu.com
traceroute 166.111.4.100
traceroute www.xju.edu.cn
traceroute www.xju.edu.cn -T
```


![MBVg4aXbmCf1w2k.png](https://s2.loli.net/2022/06/09/MBVg4aXbmCf1w2k.png)


image-20220409232055284


Linuxの`traceroute`コマンドは、パケットがホスト間を通過する経路を表示するために使用される。tracerouteコマンドを使用すると、ネットワークパケットのルーティング経路を追跡できる。デフォルトのパケットサイズは40Bytesであり、ユーザーが別途設定することもできる。


Tracerouteプログラムは、ICMPおよびIPヘッダーのTTL（Time To Live）フィールドを利用するように設計されている。まず、tracerouteはTTLが1のIPデータグラムを宛先へ送信する。経路上の最初のルーターがこのデータグラムを受信すると、TTLを1減らす。この時点でTTLは0になるため、ルーターはこのデータグラムを破棄し、ICMP time exceededメッセージを返す。tracerouteはこのメッセージを受信すると、そのルーターが経路上に存在することを認識する。続いてtracerouteはTTLが2の別のデータグラムを送信し、2番目のルーターを検出する……tracerouteは送信するデータグラムのTTLを毎回1ずつ増やして次のルーターを検出し、いずれかのデータグラムが宛先に到達するまでこの処理を繰り返す。


TracerouteがUDPデータグラムを宛先へ送信する際、送信先として選択するポート番号は、一般的なアプリケーションが使用しない番号（30000以上）である。そのため、このUDPデータグラムが宛先に到達すると、宛先ホストはICMP port unreachableメッセージを返す。tracerouteはこのメッセージを受信すると、宛先に到達したことを認識する。したがって、tracerouteにはサーバー側のいわゆるデーモンプログラムも存在しない。


Tracerouteは、ICMP TTL期限切れメッセージを送信したデバイスのIPアドレスを取得し、ドメイン名を解決する。Tracerouteは毎回、通過したルーティングデバイスのドメイン名とIPアドレス、および3個のパケットそれぞれの往復所要時間を含む一連のデータを出力する。


ここでは、tracerouteの最も簡単で一般的な使用方法である`traceroute hostname`を使用して、ホストから`www.baidu.com`および`166.111.4.100`までのルーティング状況を測定した。つまり、パケットが宛先ホストに到達するまでに通過する経路を表示した。図では、記録が1から順に番号付けされており、各記録が1ホップを表している。各ホップは1つのゲートウェイを示し、各行にある3つの時間は`ms`単位で、各ゲートウェイに3個のプローブパケットを送信してから応答が返るまでの時間を表す。また、後半の複数行がアスタリスクで表示されていることが分かる。このような状況は、ファイアウォールがICMPの応答情報を遮断している可能性があるため、関連するパケットの応答データを取得できないことを示す。一方、`-T`コマンドは`TCP SYN`を使用してプローブを行うことを表す。


### 4.4 arpの基本的な使い方


```plain text
arp –a
arp -i eth0
```


![9mabXeSE87TA3ri.png](https://s2.loli.net/2022/06/09/9mabXeSE87TA3ri.png)


image-20220409233845980


ARPはTCP/IPプロトコル群における重要なプロトコルであり、IPアドレスに対応するネットワークカードの物理アドレスを特定するために使用される。`arp`コマンドを使用すると、「アドレス解決プロトコル（ARP）」のキャッシュテーブルを表示および変更できる。ARPキャッシュには1つ以上のテーブルが含まれており、IPアドレスと、解決されたイーサネットまたはトークンリングの物理アドレスを保存するために使用される。本質的には、`ip`アドレスと`mac`アドレスの対応表である。


Linuxでは、`arp`コマンドのパラメーターaを使用すると、すべてのインターフェースのARPキャッシュテーブルを表示できる（コンピューターにインストールされた各イーサネットまたはトークンリングネットワークアダプターには、それぞれ独立したテーブルがある）。`arp -i eth0`を使用すると、指定したデバイスの`arp`キャッシュ（すなわち`eth0`の`arp`キャッシュ）を表示できる。`HWaddress`から、現在のeth0（1枚目のネットワークカード）の物理アドレスが`ee:ff:ff:ff:ff:ff`であることを確認できる。


### 4.5 netstatの基本的な使い方


`netstat`コマンドは、アクティブなTCP接続、コンピューターが待ち受けているポート、イーサネットの統計情報を表示できる。`netstat`はアクティブなTCP接続を表示する。


```plain text
netstat –a
netstat -t
```

Netstatはコンソールコマンドであり、TCP/IPネットワークを監視するための非常に有用なツールである。ルーティングテーブル、実際のネットワーク接続、および各ネットワークインターフェースデバイスの状態情報を表示できる。Netstatは、IP、TCP、UDP、ICMPプロトコルに関連する統計データを表示するために使用され、通常はローカルマシンの各ポートにおけるネットワーク接続状況の確認に用いられる。


Linuxでは、netstatコマンドのパラメーターaを使用すると、現在のすべての接続を一覧表示できる。上図では、このコマンドによって`tcp`、`udp`、`unix`プロトコルの全ソケットにおけるすべての接続が一覧表示されており、デフォルトではLISTEN関連は表示されないことが分かる。また、`metstat -t`を使用すると、ホストに`tcp`関連の項目のみを表示させることができる。


## 5、実験のまとめ


### 5.1 問題と解決方法

> 問題：tracerouteコマンドの使用時に、-bash: traceroute: command not foundエラーが発生した。解決方法：yum install tracerouteコマンドを使用して、まずtracerouteをインストールする。
> 問題：Windows 10でping -c 4 www.baidu.comコマンドを使用するとエラーが発生した。解決方法：ping /?コマンドでpingコマンドのヘルプを確認したところ、要求回数を設定するには-nを指定する必要があることが分かった。

### 5.2 感想

- 今回の実験レポートでは、よく使うネットワークコマンドに習熟し、授業で学んだ知識を検証した。この実験を通じてLinux端末のコマンドライン操作を習得し、よく使うネットワークコマンドの基本的な使い方を理解するとともに、自身のプログラミング能力を向上させることができた。
- Linux環境とWindows環境では、同じ機能を持つソフトウェアでもパラメーターが異なる場合があることを認識した。測定時にはヘルプを確認し、パラメーターオプションを正しく設定する必要がある。
- これらの一般的なネットワークコマンドを操作することで、ネットワークの各層におけるハードウェアとソフトウェアのさまざまな側面を確認し、授業で学んだ知識を検証することができた。
