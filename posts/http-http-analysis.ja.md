# **1．実験目的**

- HTTPプロトコルとそのメッセージ構造を理解する
- HTTPの動作プロセス（TCPの3ウェイハンドシェイク、リクエストとレスポンスのやり取り）を理解する
- `tcpdump`と`wireshark`を使用したHTTPパケットのキャプチャおよび分析技術を習得する

## **2．実験環境**

- ハードウェア要件：Alibaba CloudのクラウドホストECS 1台。
- ソフトウェア要件：Linux/ Windows オペレーティングシステム

## **3．実験内容**


`wget`を使用して新疆大学のホームページ**[**[www.xju.edu.cn](https://www.notion.so/dreaifenote/www.xju.edu.cn)**](**[**http://www.xju.edu.cn**](http://www.xju.edu.cn/)**)**をダウンロードし、`tcpdump`でパケットをキャプチャして`wireshark`で分析する。

1. ブラウザが使用しているHTTPのバージョンは1か1.1か？サーバーが使用しているHTTPのバージョンは何か？
2. コンピューターのIPアドレスは何か？サーバーのIPアドレスは何か？
3. サーバーからブラウザに返されたステータスコードは何か？
4. サーバーから取得したHTMLファイルはいつ変更されたものか？
5. ブラウザに返されたコンテンツは何バイトか？
6. 上記で回答したフィールド以外に、ヘッダーにはどのようなフィールドがあるか？パケット内容ウィンドウで生データを確認したとき、パケット一覧に表示されていないヘッダーはあるか？

### **2.2 問題への回答**

> ブラウザが使用しているHTTPのバージョンは1か1.1か？サーバーが使用しているHTTPのバージョンは何か？ブラウザが使用しているHTTPのバージョンは1.1であり、サーバーが使用しているHTTPのバージョンも1.1である。サーバー ブラウザ コンピューターのIPアドレスは何か？サーバーは？コンピューターのIPは172.16.2.155、サーバーのIPは100.100.109.104である。サーバーからブラウザに返されたステータスコードは何か？返されたステータスコードは200であり、リクエストが正常に処理されたことを示す。サーバーから取得したHTMLファイルはいつ変更されたものか？日時はTue, 07 Jun 2022 07:02:12 GMTである。ブラウザに返されたコンテンツは何バイトか？ブラウザに返されたコンテンツは0バイトである。上記で回答したフィールド以外に、ヘッダーにはどのようなフィールドがあるか？パケット内容ウィンドウで生データを確認したとき、パケット一覧に表示されていないヘッダーはあるか？HTTPリクエストメッセージには、Hostフィールド、connectionフィールド、Acceptフィールド、User-agentフィールド、Accept-Encodingフィールドなども含まれている。HTTPレスポンスメッセージには、serverフィールド、connectionフィールドなども含まれている。

## **5、実験のまとめ**


### **5.1 問題と解決方法**

> 問題：Xftpを使用してサーバーに接続した際、接続エラーが発生した。解決方法：大学のネットワークに接続すると正常に戻り、調査の結果、サーバーのファイアウォールが原因であることが判明した。
